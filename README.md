# 🎨 Proyecto Canvas Responsivo con Diseño Moderno

## 📌 Descripción

Este proyecto utiliza la API Canvas de HTML5 para dibujar un rectángulo que se adapta dinámicamente al tamaño de la ventana del navegador.

El canvas ocupa el **50% del ancho y 50% del alto de la pantalla**, tiene un diseño moderno con:
- Bordes redondeados
- Sombra elegante
- Estilo visual limpio
- Color personalizable

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- API Canvas (2D)

---

/mi_proyecto

---

## ⚙️ Funcionamiento

1. Se obtiene el elemento `<canvas>` desde el HTML.
2. Se ajusta su tamaño al 50% del ancho y alto de la ventana.
3. Se obtiene el contexto de dibujo 2D.
4. Se define el color de relleno.
5. Se dibuja un rectángulo que ocupa todo el canvas.

---

## 🎨 Diseño

El canvas incluye:

- `border-radius` para esquinas redondeadas.
- `box-shadow` para efecto de profundidad.
- Colores personalizados con RGB.

---

## 🖥️ Cómo ejecutar el proyecto

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Disfruta el resultado visual.
